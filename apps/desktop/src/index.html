Recast

Select text in any app, then press ⌘⇧Space.

It lifts off into Recast as an object: a time, a person's email, an error, a sentence, with the app it came from. Grab a few, drag one onto another to press them together, then choose where it goes.

Allow Recast to read what you select. macOS asks once: System Settings → Privacy & Security → Accessibility → turn on Recast.
